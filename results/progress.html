The core idea

STU = the differential-testing frontier. c2rust restructures code, so fuzzing at an arbitrary function makes "divergences" that are really bad-boundary artifacts. The contribution is predicting where a differential harness is valid (inputs constructible, outputs comparable, no UB / unmet precondition) — turned into a labeled boundary-validity dataset plus the static features that explain it.
Novelty (literature-checked): not the fuzzing, but the static boundary-validity prediction + an evidence-backed, independently-audited label taxonomy.
