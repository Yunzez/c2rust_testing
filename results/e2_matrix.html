The prompt — no cheating on names

The raw-LLM translations were told to rename aggressively, and told nothing about the correspondence.

Adversarial, not manufactured. The prompt commands renaming — so the name-equality collapse is genuine. We test the matcher on the hardest naming case, not a contrived one.
No leakage. The prompt only asks for "roughly one Rust function per C function." It never says which Rust function maps to which C function. The matcher sees only structure.
You are an expert C-to-Rust translator. Translate the given C source into a single,
self-contained, idiomatic, safe Rust library crate, semantically equivalent to the C.
Rules:
- Rename functions to idiomatic Rust style (snake_case, descriptive names). This
  renaming is intentional and required — do NOT keep the original C names, and do
  NOT use #[no_mangle] or extern "C".
- Keep roughly one Rust function per C function (preserve the call structure).
- Use only the Rust standard library. The crate must compile as a lib crate.

What the matrix will say

Names-kept columns validate; renamed columns win

c2rust / Laertes / C2SaferRust / CROWN keep names, so name-equality is already ~1.0 — the matcher must recover that blind despite ptr→slice / ownership reshaping (proving it isn't cheating). SACTOR / PtrTrans / raw-LLM rename, so name-equality collapses and the matcher's margin is the result.

Homogeneity is the real difficulty axis

Not LOC — how many functions share one io-shape. lil (55/128 identical shapes) and tulipindicators (~100 near-identical indicators) are where per-function signals saturate and call-graph topology carries the match.

Ground-truth economics

~40 cells are near-free: the name-preserving tools mean name-equality IS the truth, so we just check the blind matcher recovers it. Only the ~6 renaming-tool cells + the raw-LLM column need hand labels.

The UB gate does not apply here

E1 excludes urlparser because its C is UB — but matching is static, it never runs the C. So urlparser's Rust artifacts ARE matchable in E2: a cell E1 had to drop becomes live evidence here.
